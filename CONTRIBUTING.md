# Contributing

Thanks for helping. Good contributions: fixes against LinkedIn's current docs, new tests, clearer skills, translations, better writing guidance.

## Ground rules
1. **Official API only.** No scraping, no browser automation, no unofficial endpoints.
2. **Human approval stays.** Nothing may publish content a person has not approved.
3. **No secrets, ever.** Run `li-secrets-scan` before committing (`li-secrets-scan --install-hook` makes it automatic). Test fakes need `secretscan:allow` on the same line.
4. **Original words.** Write guidance yourself; cite LinkedIn's pages instead of copying them. Do not paste text from other projects.
5. **Tests.** New behaviour needs a test. Tests must not touch the network or real credentials (use `tests/helpers.py`).

## Run the tests
```bash
python -m unittest discover -s tests
python -m linkedin_automation.secretscan      # with PYTHONPATH=src, or after pip install -e .
```

## Updating the LinkedIn knowledge
Each file in `skills/linkedin-api/references/` names its source pages. When LinkedIn changes something, update the file, change the snapshot date in `SKILL.md`, and add a line to `CHANGELOG.md`.

## Pictures
README images are generated by `docs/images/build.py` (needs Playwright). Edit the script, rebuild, commit the PNGs.

# LinkedIn comments and replies

Good comments are the cheapest way to be seen by the right people. Bad ones ("Great post! 👏") are noise. The goal: one useful sentence or two that a stranger would be glad they read.

## How it works (and why it stays manual)
- The **user pastes** the post text (and the comment they want to answer). LinkedIn's API does not let anyone read other people's posts, and LinkedIn's Developer AI Policy restricts creating comments from LinkedIn content retrieved through the API. Text a person pastes in by hand is their own input.
- You draft 2-3 options. **The user posts the comment themselves** in LinkedIn (or, for their own posts, may use the API only after approving the text).
- Never send a comment automatically. Never mass-comment.

## Before drafting
1. Read `VOICE.md` if it exists (see `linkedin-writer`).
2. What is the post really about, and what does the author want from readers?
3. What can the user honestly add: a related experience, a number, a counter-example, a useful resource, a sharper question? **If the user has nothing real to add, say so and suggest a simple reaction instead of a fake comment.**

## Comment types that work
| Type | Shape |
|---|---|
| Add a detail | "We saw the same thing with X; what changed it for us was Y." (only if true) |
| Respectful disagreement | "I'd add one condition: this holds when..., not when..." |
| Ask a real question | A specific follow-up the author would enjoy answering |
| Connect two ideas | Link their point to something the user knows |
| Thank with substance | Name the one thing that was useful and why |

## Rules
- 1-3 sentences, 15-60 words. No hashtags, no links, no self-promotion, no emoji spam.
- Never invent experiences, numbers or credentials for the user.
- Do not flatter. Do not summarise the post back to its author.
- Reply to comments on the user's own posts within a day: thank, answer the question, or add the next thought; keep the thread alive with a question when it helps.
- Tone for criticism or trolls: calm, brief, no argument; one clarifying reply, then stop.
- Sensitive topics (politics, health, layoffs of named people): suggest not commenting.

## Output
Three options labelled Short, Medium, Question, each with one line on why it works, and a note if any option relies on a fact the user must confirm.

# Code of Conduct

Be kind, be specific, assume good faith. Disagree with ideas, not people.

Not welcome here: harassment, discrimination, personal attacks, spam, and requests for help with scraping, fake accounts, mass or deceptive posting, or anything that breaks LinkedIn's terms. Maintainers may edit or remove comments, issues and pull requests that break these rules and may block repeat offenders.

Report concerns by opening an issue titled "conduct" (without personal details) or by contacting the maintainers through the profile of this repository's owner.

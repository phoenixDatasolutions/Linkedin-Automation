# Roadmap

Honest list of what is next. Order is a guide, not a promise. Ideas and pull requests welcome (see CONTRIBUTING.md).

## Next (0.2)
- [ ] **Live-verified guide**: run the full setup against a real account and record exactly what each LinkedIn screen shows (screenshots in the setup guide).
- [ ] **Video posts** (`li-post video`): multipart upload, captions, thumbnail.
- [ ] **Refresh tokens** for approved partners (`li-auth refresh`).
- [ ] **Company Page analytics**: `li-stats page` (share statistics for many posts in one call, follower statistics).
- [ ] **Edit a published post** (`li-post edit`, partial update of commentary).

## Later
- [ ] A small web page that explains OAuth and shows the setup steps interactively.
- [ ] Webhook receiver example for Page notifications (validation + signature checks).
- [ ] Windows installer notes and tests in CI.
- [ ] Translations of the setup guide.
- [ ] A skill for repurposing a blog post into posts (with the same approval rules).

## Not planned (on purpose)
- Scraping, browser automation, unofficial endpoints.
- Auto-posting without a person's approval.
- Mass commenting or engagement pods.
- Reading other people's posts (LinkedIn closed that permission to everyone).
